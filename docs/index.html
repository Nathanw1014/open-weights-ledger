How to read this page

What this is: a dated record of model weight file hashes scraped from Hugging Face, which other services list the same hash, and what has changed since. A matching hash shows the bytes are the same as the ones recorded here. It does not show that a model is safe.

Confirmed by a second service means ModelScope lists the same sha256 for the file, independently of Hugging Face.

Pirate Face torrents are pinned to a repo commit. A pinned torrent is a second copy of the bytes, but its per-file hashes are copied from Hugging Face, so it is not an independent witness and does not count as confirmation here. Repos that have not been looked up on Pirate Face yet show as "not checked", which is different from "no torrent".

Superseded means the path now has a different hash at main. Removed means the path is no longer at main. On superseded rows a different ModelScope hash only means ModelScope carries the newer version.

Older versions (superseded and removed hashes) are kept in separate files and loaded on demand. A pasted hash loads only the one file it could be in. Lists that need all of them say so and offer a button.

Abliterated or uncensored is derived from repo names and tags (abliterated, obliterated, uncensored, heretic and similar), so it can miss a repo or include one by mistake. Gated means the repo needs a Hugging Face login, so its hashes could not be read. It is not an outage.

Versions: v1 is the first hash on record for a file. "v2 (+1)" means the file was re-uploaded once and this is the second hash. A copy downloaded before a re-upload has the older hash.

All dates and times are UTC.
